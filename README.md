🔐 Security Principles

| Principle                    | How I apply it                                                              |
| ---------------------------- | --------------------------------------------------------------------------- |
| No secrets in GitHub         | Passwords, tokens, keys, IPs, and private configs stay out of public repos  |
| Least privilege              | Services, users, containers, and tokens get only what they need             |
| Document everything          | Every project includes setup, rollback, troubleshooting, and security notes |
| Repeatable builds            | Repos should help me rebuild, not just remember what I clicked              |
| Monitoring before production | Logs, alerts, and health checks come before trusting a service              |
| Backups before changes       | Snapshot or backup first, change second                                     |
| Small trusted steps          | One change at a time, tested and documented                                 |
